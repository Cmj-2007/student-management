# 考核项目二：MySQL环境搭建（加分项）

## 任务要求

在你的本机环境（Windows/macOS/Linux）上成功安装并配置MySQL数据库。

**说明**：此项目为可选加分项，不影响基础考核成绩。

## 学习资源

**搜索关键词：** "MySQL安装教程 [你的操作系统]"

**资源网站：** MySQL官方文档、菜鸟教程、CSDN、B站等

**AI工具：** 可咨询ChatGPT、豆包等

## 验证标准

### 1. MySQL服务正常启动
能在系统中确认MySQL服务正在运行

### 2. 命令行连接成功
执行 `mysql -u root -p` 能成功登录

**成功登录示例：**
